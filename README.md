# 🗺️ Интерактивная карта и журнал заданий Pathfinder Kingmaker

Удобный инструмент для ведущих и игроков настольных ролевых игр. Позволяет наглядно управлять исследованием территорий, перемещением вашей группы по гексам и вести учет всех игровых квестов в одном месте.

---

## 🌟 Возможности для игроков и мастеров

### 1. Глобальная стратегическая карта
* **Исследование земель:** Вся карта изначально скрыта «туманом войны». Новые гексы открываются по мере продвижения вашей группы.
* **Перемещение отряда:** Вы можете выставить флаг группы в любую точку карты.
* **Настройка биомов:** Для каждого гекса задается тип местности (от `равнин 🌾` до `гор ⛰️` и `болот 🐸`), сложность прохождения и уровень опасности. Можно красить зоны, давать им названия и оставлять заметки.
* **Удобное управление:** Карту можно свободно перетаскивать мышкой (или свайпом на смартфонах) и масштабировать колесиком.

### 2. Карты для тактических расчетов
Переключение в режим **Camp Mode** превращает интерфейс в квадратную тактическую сетку для моделирования лагеря, отдыха или боевых столкновений:
* **Размещение участников:** Расстановка токенов `Героев 👑` и `Монстров 👿` простым перетаскиванием `Drag-and-Drop`.
* **Препятствия и ландшафт:** Разметка непроходимых стен `🧱`, `разрушаемых ящиков 📦`, `густых лесных чащ 🌲`, `скользкого льда ❄️` или `липкой паутины 🕸️`.
* **Автоматический просчет путей:** При выборе персонажа и наведении на любую клетку система строит кратчайший маршрут, считает цену перехода в футах и переводит её в **количество действий (до 3 действий за ход)**.
* **Механика прыжков (Jumps):** Алгоритм автоматически рассчитывает возможность перепрыгнуть препятствия (`камни 🪨`, `кусты 🌿`), помечая клетки взлета `JUMP 🦘` и приземления `LAND 🎯`.
* **Зоны видимости и ауры:** Герои рассеивают тактический туман войны, а параметры радиуса, конуса видимости (с учетом направления взгляда N/S/E/W) и линии видимости динамически подсвечивают карту цветом персонажа.

### 2. Управление точками интереса
Каждую ячейку карты можно детально настроить:
* Отмечать объекты: `Достопримечательности 🏛️`, `Ресурсы 💎`, `Стандартные задания ⚜️` или `Тайны ❓`.
* Задавать тип местности (от равнин до опасных болот и гор).
* Указывать сложность прохождения и уровень опасности региона.
* Красить зоны в разные цвета, давать им названия и оставлять текстовые заметки.

### 3. Удобный журнал квестов
* **Связь с картой:** Задания создаются прямо внутри нужного гекса и автоматически попадают в общий список.
* **Сортировка:** Квесты разделены на две удобные вкладки — «Текущие» и «Завершенные».
* **Быстрый поиск:** При клике на задание в журнале карта сама центрируется на нужном месте и подсвечивает целевую ячейку яркой красной вспышкой.

### 4. Встроенная атмосфера
* В комплекте идет музыкальный плеер, который автоматически загружает музыку из Pathfinder Kingmaker.
* Поддерживает случайное воспроизведение треков, повтор и настройку громкости для создания правильного фона во время партии.

### 5. Сохранение и перенос прогресса
* Все изменения автоматически сохраняются в браузере — прогресс не пропадет при случайном закрытии вкладки.
* Карту со всеми заметками и квестами можно в один клик скачать в виде файла, чтобы перенести на другой компьютер или передать игрокам.

## 🚀 Варианты запуска карты

Базовый функционал карты (редактирование гексов, туман войны, журнал квестов и сохранение данных) работает автономно и не требует сложных настроек. Однако для полноценной работы фоновой музыки браузерам нужен локальный сервер. Выберите наиболее удобный для вас вариант запуска:

### Вариант 1. Обычный запуск (Быстрый, без музыки)
Если вам нужна только карта и квесты, а музыку вы включаете отдельно (например, в Discord или плеере):
1. Просто зайдите в папку с проектом.
2. Дважды кликните по файлу **`index.html`**, чтобы открыть его в любом современном браузере.
   *Вся логика карты, журнал заданий, импорт/экспорт и автосохранения будут работать на 100%. Музыкальный модуль в данном режиме работать не будет.*

### Вариант 2. Через редактор VS Code (Рекомендуется для игры с музыкой)
1. Откройте папку с проектом в редакторе **Visual Studio Code**.
2. Перейдите во вкладку **Расширения** (Extensions) на панели слева (или нажмите `Ctrl+Shift+X`).
3. Найдите и установите расширение **Live Server**.
4. В правом нижнем углу окна VS Code нажмите кнопку **Go Live**. Проект автоматически запустится локально, и музыкальная панель станет полностью активной.

### Вариант 3. Через командную строку (Без установки дополнительных программ)
Если на вашем компьютере установлен Python или Node.js, откройте терминал или командную строку прямо в папке проекта и введите одну из команд:

* **Через Python:**
  ```bash
  python -m http.server 8000
  ```
  *(После этого откройте в браузере адрес `http://localhost:8000`)*

* **Через Node.js:**
  ```bash
  npx serve
  ```
  *(После этого откройте адрес, который утилита выведет в консоль, обычно `http://localhost:3000`)*

### Вариант 4. Запуск на смартфонах и планшетах (Для игры за столом)
Если вы хотите управлять картой и музыкой с планшета во время партии:
1. Запустите локальный сервер на компьютере по инструкции из **Варианта 2** или **Варианта 3**.
2. Подключите компьютер и планшет к одной сети Wi-Fi.
3. Узнайте локальный IP-адрес вашего компьютера (например, `192.168.1.50`).
4. На планшете введите в адресную строку браузера этот IP и номер порта через двоеточие: например, `http://192.168.1.50:8000`.
